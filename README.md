# 💈 Barber Shop Business Dashboard

An interactive business analytics dashboard built in Microsoft Excel
to monitor and analyze barber shop performance across multiple US cities.

## 📂 File Structure

This project contains one Excel file with three sheets:

| Sheet | Description |
|-------|-------------|
| **Dashboard** | Visual overview with KPI cards, charts, and slicers |
| **Pivot** | Pivot tables that power all the dashboard charts |
| **Data** | Raw transaction records (2025–2026) |

## 📊 Dashboard KPIs

| Metric | Value |
|--------|-------|
| Average Daily Service | $347 |
| Total Customers | 2,192 |
| Total Revenue | $759,740 |
| Total Profit | $341,696 |

## 📈 Charts Included

- **Branch Profit** – Which location earns the most
- **Daily Revenue Trend** – Revenue breakdown by service type
- **Monthly Revenue & Profit** – Month-by-month performance
- **Customer Count by Type** – New vs Regular vs Walk-in split
- **Transaction by Year & Month** – Yearly volume comparison
- **Revenue by City** – City-level performance
- **Count by Employee Service** – Which barber serves the most customers

## 🗂️ Pivot Tables

The Pivot sheet contains pivot tables for:

1. Average Daily Service
2. Customer Count by Type
3. Revenue by City
4. Transaction by Year & Month
5. Daily Revenue Trend (by Service)
6. Profit by Branch
7. Monthly Revenue & Profit

## 🔍 How to Use

1. Download `dashboard.xlsb.xlsx`
2. Open in **Microsoft Excel 2016 or later**
3. Go to the **Dashboard** tab
4. Use the **slicers** on the left side to filter by:
   - Year (2025 / 2026)
   - Month (Jan–Dec)
   - City (Chicago / Dallas / Los Angeles / New York)
